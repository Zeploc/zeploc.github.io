Gameplay Flow

An Unreal Engine plugin that extends the FlowGraph plugin to use the Gameplay Ability System in flows, with latent conditions and dynamic hooking into actors as levels load and actors spawn. Gameplay sequences and conditions are built as nodes, without hand-written state machines.

Type
Unreal Engine plugin
Engine
Unreal Engine 5.4+
Builds on
FlowGraph · Gameplay Ability System
Used in
Kinetic and other projects

What it does

  • Latent condition nodes that recheck when a state changes, and fire once the conditions are met
  • A condition framework, with ability conditions and gameplay tag conditions (criteria and counts)
  • Gameplay actor targeting: player, owner, instigator or a level actor
  • Distributors, trigger distributors and volumes that apply flows to target actors
  • An actor registry, so flows can find actors by ID as they spawn or load
  • Live debugging of flow nodes, and Blueprint-friendly classes throughout

A flow graph

How it works

Two runtime modules
GameplayFlow, and a separate Gameplay Actor Registry module.
Built on FlowGraph
A flow component and flow asset extend FlowGraph's own, so the existing flow tools still work.
Registry subsystem
A game instance subsystem owns the registry; actors register and unregister through an interface and delegates.
Tested and built by CI
Automation specs cover the registry; a Jenkins pipeline builds for Unreal Engine 5.7 and reports the tests.
