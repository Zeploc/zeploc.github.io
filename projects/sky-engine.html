Project · Personal project · C++

Sky Engine

My own game engine and editor in C++, built to learn how engines work from the inside. A Windows engine DLL powers an ImGui editor, a standalone game runtime and a game module that hot-reloads in the editor. OpenGL is fully supported, and a Vulkan back end is in development.

Type
Personal project
Language
C++20
Graphics
OpenGL · Vulkan in progress
Since
November 2018
Build
Premake · Visual Studio

What it does

  • Platform, window and graphics API abstraction
  • Macro-based reflection for serialisation and editor inspection
  • An asset manager that scans, then loads assets only when needed
  • Entities and components, with a perspective and orthographic camera
  • Typed materials whose shader parameters appear in the editor automatically
  • Configs editable in the editor, with hot reload

Showcase

The editor

  • Scene editing

    A scene outliner and a viewport with selection and transform gizmos.

  • Property inspector

    Fields are built automatically from each class's serialised variables.

  • Content browser and tools

    A content browser, console log and material editor; materials and levels are created in the editor.

  • Play in editor

    The scene is deep-copied by serialising it, and a free-fly camera can watch the running game.

  • Hot reload

    The modules panel builds a game module and reloads the scene around it.

  • Input

    Keyboard, mouse and Xbox controller.

Architecture

Projects
The engine (a shared library), the editor, a game runtime, a game module and a GoogleTest suite.
Classes by name
Class registration and factories, so objects can be created by name from saved files.
Assets
Plain-text asset and level files; the first line names the class. A handle is kept separate from the loaded content.
Scene and world
A scene is the content; a world is a running instance with its own camera, tick policy and input routing.
Rendering
A scene renderer with a framebuffer abstraction for off-screen rendering, behind the graphics API layer.
Libraries
ImGui and ImGuizmo, glm, GLFW, GLEW, Assimp, FMOD, Box2D, FreeType and SOIL2.
