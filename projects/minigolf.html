Project · Personal project

Minigolf

An online multiplayer minigolf game: host or join a game, then play the holes in VR or on a screen.

Type
Personal project
Role
Solo
Years
2020 – 2021
Engine
Unreal Engine 4

About the project

Host or join a game from the lobby, then play the holes with name tags and a scoreboard. The course is built from modular platform pieces, with swinging obstacles and, later, portals.

What I built

  • A network session system: hosting, a server list, joining and the lobby
  • Multiplayer holes, scores and name tags
  • A VR player, alongside the standard ball player
  • Modular course pieces and a platform editor
  • Swinging obstacles and portals
